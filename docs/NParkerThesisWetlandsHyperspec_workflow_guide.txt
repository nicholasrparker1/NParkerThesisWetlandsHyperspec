NParkerThesisWetlandsHyperspec
Quick Start + What To Change + Workflow Guide
==================================================

Purpose
-------
This repo is for extracting, cleaning, and plotting hyperspectral spectra from NEON ROCX H5 reflectance data, mainly for wetland / soil / water point comparison.

The most common workflow is:
1. point locations in CSV
2. convert lat/lon to raster row/col
3. snap to nearest valid pixel if needed
4. extract ROI-based spectral statistics
5. clean / mask bad spectral bands
6. plot one or more spectra
7. save figure to outputs

--------------------------------------------------
MAIN FILES AND WHAT THEY DO
--------------------------------------------------

1) src/config.py
   Central settings file.
   This is the first file a new user should check.

   It defines:
   - project directories
   - raw data folder
   - processed data folder
   - output figure folder
   - important H5 dataset paths

   Typical important variables:
   - DATA_RAW
   - DATA_PROCESSED
   - FIGURES
   - REFLECTANCE_PATH
   - WAVELENGTH_PATH

2) src/io_hyperspectral.py
   Low-level H5 reading and coordinate utilities.

   Typical responsibilities:
   - open/read H5 metadata
   - read map info
   - convert lat/lon -> row/col
   - support reading hyperspectral arrays

3) src/preprocess.py
   Spectral cleaning utilities.

   Main jobs:
   - define bad wavelength windows
   - define invalid reflectance rules
   - create masks
   - prepare spectra for plotting

   Important functions:
   - build_bad_band_mask(...)
   - build_invalid_value_mask(...)
   - clean_spectrum(...)
   - spectrum_for_plot(...)
   - iqr_summary(...)

4) src/scripts/pull_spectrum_latlon.py
   Core single-point / ROI extraction logic.

   Main jobs:
   - take one lat/lon point
   - convert to row/col
   - snap to nearest valid pixel
   - extract ROI spectral statistics
   - return wavelength, median spectrum, lower percentile, upper percentile, ROI bounds

   This is one of the most important files in the repo.

5) src/scripts/pull_spectra_overlay.py
   Main multi-point plotting script.

   Main jobs:
   - read CSV of points
   - loop through each point
   - call pull_spectrum_latlon helpers
   - apply spectral cleaning/masking
   - overlay spectra on one figure
   - plot IQR shading
   - save figure

6) src/scripts/roi_transect.py
   Used to draw or inspect ROI/transect locations on imagery.

7) src/scripts/roi_box.py
   Used for plotting ROI boxes on raster imagery.

8) src/scripts/inspect_h5.py and src/scripts/make_h5_report.py
   Used for understanding the H5 structure and checking dataset contents.

--------------------------------------------------
MOST COMMON ORDER OF OPERATIONS
--------------------------------------------------

When you run:

python -m src.scripts.pull_spectra_overlay --points data/processed/transect_points.csv --roi 9 --snap 40

the code flow is roughly:

1. pull_spectra_overlay.py starts
2. reads points CSV
3. finds the H5 file in data/raw
4. reads map info once
5. for each point:
   a. convert lat/lon -> row/col
   b. snap to nearest valid pixel
   c. call read_roi_stats_spectrum(...) from pull_spectrum_latlon.py
   d. get back:
      - wavelengths
      - median spectrum
      - lower percentile
      - upper percentile
      - ROI bounds
   e. apply cleaning / bad-band masking from preprocess.py
   f. plot line + IQR envelope
6. format plot
7. save figure to outputs/figures

Simple summary:
config -> io_hyperspectral -> pull_spectrum_latlon -> preprocess -> pull_spectra_overlay

--------------------------------------------------
WHAT A NEW USER MUST CHANGE
--------------------------------------------------

Every time a new person uses this repo, they should check these items first.

A) In src/config.py
-------------------
These are the most important things to verify.

1. Project/data folders
   Make sure these point to the correct repo folders.

2. H5 dataset paths
   These must match the specific H5 product being used.

   Common expected values:
   REFLECTANCE_PATH = "ROCX/Reflectance/Reflectance_Data"
   WAVELENGTH_PATH = "ROCX/Reflectance/Metadata/Spectral_Data/Wavelength"

3. Any other metadata paths
   For example map info / EPSG paths if used elsewhere in the repo.

If the H5 product name changes, or the H5 internal structure changes, config.py is the first place to update.

B) In the points CSV
--------------------
The CSV used by overlay scripts should contain:

id,lat,lon

Example:
id,lat,lon
1,43.12345,-77.12345
2,43.12355,-77.12365
3,43.12370,-77.12390

for this instructions document, this file containing the points is called transect_points.csv

If the column names change, update the CSV reader in pull_spectra_overlay.py.

C) In the raw data folder
-------------------------
Put the target H5 file in the expected raw-data directory.

Usually:
data/raw/

If there are multiple H5 files in the folder, the current script may just take the first one it finds.
If that becomes a problem, change the script so the H5 filename is passed as an argument.

D) Plot settings / thresholds
-----------------------------
If a new user wants different masking or cleaning behavior, the main places to change are:

1. src/preprocess.py
   - bad wavelength windows
   - reflectance thresholds
   - narrow-band masking choices

2. src/scripts/pull_spectra_overlay.py
   - include_narrow=True or False
   - ROI size
   - snap radius
   - title text
   - output filename rules

--------------------------------------------------
WHAT TO CHANGE FOR COMMON USE CASES
--------------------------------------------------

1) Change the points file
-------------------------
Command:
python -m src.scripts.pull_spectra_overlay --points data/processed/transect_points.csv --roi 9 --snap 40

Change:
--points data/processed/transect_points.csv

Use a different CSV path if needed.

2) Change ROI size
------------------
Change:
--roi 9

Examples:
--roi 3
--roi 9
--roi 15

Meaning:
- smaller ROI = less mixing, tighter IQR
- larger ROI = more averaging, often wider IQR

3) Change snap radius
---------------------
Change:
--snap 40

Examples:
--snap 10
--snap 40
--snap 75

Meaning:
- smaller snap radius = stricter, less relocation
- larger snap radius = more likely to find a valid nearby pixel

4) Change percentile envelope
-----------------------------
Change:
--p_lo 25 --p_hi 75

Examples:
--p_lo 10 --p_hi 90
--p_lo 25 --p_hi 75

Meaning:
- 25/75 = IQR-style spread
- 10/90 = wider variability envelope

5) Change bad spectral windows
------------------------------
Edit:
src/preprocess.py

Look for:
- DEFAULT_BROAD_BAD_WINDOWS_NM
- DEFAULT_NARROW_BAD_WINDOWS_NM

This is where to change masked wavelength ranges.

6) Turn narrow masking on or off
--------------------------------
Edit where build_bad_band_mask(...) is called in the plotting script.

Example:
include_narrow=True
or
include_narrow=False

Use this if you want to compare:
- broad-only masking
- broad + narrow masking

--------------------------------------------------
TYPICAL COMMANDS
--------------------------------------------------

1) Overlay several spectra from a points CSV
python -m src.scripts.pull_spectra_overlay --points data/processed/transect_points.csv --roi 9 --snap 40

2) Compare smaller ROI
python -m src.scripts.pull_spectra_overlay --points data/processed/transect_points.csv --roi 3 --snap 40

3) Compare larger ROI
python -m src.scripts.pull_spectra_overlay --points data/processed/transect_points.csv --roi 15 --snap 40

4) Test snap sensitivity
python -m src.scripts.pull_spectra_overlay --points data/processed/transect_points.csv --roi 9 --snap 10
python -m src.scripts.pull_spectra_overlay --points data/processed/transect_points.csv --roi 9 --snap 75

--------------------------------------------------
HOW TO INTERPRET THE OUTPUTS
--------------------------------------------------

General guide:
- median line = representative ROI spectrum
- shaded band = within-ROI spread (percentile envelope)
- masked gaps = bands intentionally hidden because they are unreliable
- wider shaded envelope = more heterogeneity inside the ROI
- very dark, low spectrum everywhere = possible water / shadow / very dark surface
- stable shape across ROI sizes = more robust signal
- strong changes across ROI or snap settings = possible mixed pixels or unstable sampling

--------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------

1) ImportError for REFLECTANCE_PATH or WAVELENGTH_PATH
Cause:
- missing variables in src/config.py

Fix:
- define the H5 dataset-path constants in config.py

2) No .h5 files found
Cause:
- wrong raw-data folder
- file not copied into data/raw

Fix:
- place H5 file into the correct raw directory
- verify config.py paths

3) No valid pixel within snap radius
Cause:
- point falls on invalid area
- snap radius too small
- coordinates wrong

Fix:
- increase --snap
- verify coordinates
- inspect point on map

4) Spectrum looks too dark / too strange
Cause:
- point may be water, shadow, edge area, or mixed ROI

Fix:
- inspect the point on imagery
- reduce ROI
- compare different snap radii

5) Plot crashes after edits
Cause:
- shape mismatch or import mismatch

Fix:
- check preprocess.py function names
- confirm wl / med / lo / hi arrays have same shape
- confirm config variable names match imports

   - preprocess.py
   - pull_spectrum_latlon.py
   - pull_spectra_overlay.py
   - roi_transect.py

   *.pyc
